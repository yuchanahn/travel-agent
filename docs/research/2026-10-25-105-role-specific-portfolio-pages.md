# 105 · 두 공고의 실제 포트폴리오 페이지와 추적 화면 자리

Notion: [토스](https://app.notion.com/p/404d058c022e813091e8dc0606bbbdf5), [토스증권](https://app.notion.com/p/404d058c022e8176a4dacfe26bc290d9).

## 요청과 반영

사용자는 공고별로 구분한 실제 포트폴리오 페이지를 요구했다. 답변 A/B 비교처럼 보이는 화면보다 호출 스택·Context 추적 화면을 제공할 수 있다고 했으며, 그런 장면이 보이도록 구성하기를 제안했다.

기존 두 목차 페이지를 공고별 실제 원고로 전환했다. 기술명 제목 아래 짧은 구현 설명과 선택 이유를 쓰고 구조도와 기존 제품 화면을 배치했다. 토스는 고객의 대화·기억·정보 탐색·계획서 흐름, 토스증권은 실행 경계·관측·메모리·데이터·평가·상태 복원을 중심으로 순서와 설명을 달리했다. 같은 원고에서 회사 이름만 바꾸지 않았다.

## 시각 자료와 남은 작업

각 페이지에 제품 홈과 사용자 확정 화면을 연결했다. 실행 비교표 이미지는 넣지 않았다. 모델 요청·도구 인자/결과·다음 입력, 원문/요약/검색 Context, source ID와 실제 전달 발췌를 볼 수 있는 화면의 자리를 구체적으로 표시했다.

호출 스택은 함수의 실제 호출 관계이고 trajectory는 모델·도구 행동 기록이다. 이를 같은 이름으로 섞지 않고 화면 종류에 맞춰 연결한다. 사용자 제공 캡처를 아직 받지 않았으므로 새 구현이나 확보한 증거로 표시하지 않았다.

## 확인

Notion을 다시 읽어 두 페이지에 실제 본문이 있고 제목·기술·선택 이유·구조도가 저장됐는지 확인했다. 토스는 구조도4개, 토스증권은5개이며 기존 이미지는 각2개다. 두 페이지 모두 실행 비교표 이미지가 없고 추적·Context 화면 자리가 남아 있다. 링크·문서 구조·원고 내용은 오프라인에서 검사한다.

현재 결과는 사용자 검토와 캡처 교체를 기다리는 실제 원고 초안이다. 자기소개서와 PDF는 이번에 만들지 않았다. 제품 코드·모델·새 검색·추천 실험도 없으며 실험용 도구 로그를 만들지 않았다.
