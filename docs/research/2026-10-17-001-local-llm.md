# 001 — 로컬 LLM 공급과 초기 실패

## 문제에서 검증까지 — 로컬 생성은 가능했지만 좋은 여행 답변은 아니었다

보강일: 2026-10-17. 아래는 기존 기록·보존 산출물에 근거한 보강이며, 당시 기록은 뒤에 남겼다. 재실행 출력에는 시점과 코드 버전을 별도로 표시한다.

**흐름:** 차 없이 여행한다는 쿼리 → 조건을 어긴 실제 응답 → 연결 성공과 품질 실패를 분리

### 1. 문제 정의 — 요청과 초기 결과

실제 입력은 ‘서울에서 출발해 차 없이 두 명이 총 40만 원 예산으로 1박 2일 여행을 하려고 해. 후보 지역 두 곳과 선택 이유를 세 문장 이내로 알려줘. 확정 가격은 필요 없어.’였다. 좋은 답변의 기준은 차량 없음·문장 수·미확인 가격 고지다. 아래는 당시 저장된 모델 응답이다. 당시 터미널 stdout 전체는 별도로 보존되지 않았으므로 결과 JSON을 stdout이라고 부르지 않는다.

출처: `ollama-smoke-test-results.json`. 종류: **보존된 결과 파일 원문 발췌**. 원본 파일 SHA-256: `c900a0b5142cbecb765fd7ad1738241d6669dcd9b76e95cab063b8af2e3c435a`. 발췌 내용은 고치지 않았다.

```json
  "korean_response": "**1. 서울 근교 자연공원 (예: 이천 화천)**\n서울에서 차로 30 분 내외로 접근 가능하여 이동 부담이 적습니다.\n산책과 간단한 식사만으로도 예산을 효율적으로 사용할 수 있습니다.\n자연 친화적인 분위기에서 두 명이 여유롭게 시간을 보내기 좋습니다.\n\n**2. 서울 외곽 역사 문화 지역 (예: 안양 또는 평택)**\n교통 인프라가 잘 되어 있어 접근성이 높고 다양한 체험 프로그램이 가능합니다.\n역사적 유적과 현지 음식으로 구성된 저렴한 코스 구성이 용이합니다.\n문화적 경험을 쌓으면서도 40 만 원 예산 내에서 만족스러운 여행이 될 것입니다.",
```


### 2. 문제 분석

차량이 없다는 입력에도 자동차 이동을 설명했고 세 문장 제한도 넘겼다. 도구 호출 인자는 맞았지만 가상 가격을 최종 답변에서 고지하지 않았다. 응답과 tool call이 나온다는 검사만으로는 이 실패를 잡을 수 없었다.

### 3. 연구 과정

8GB VRAM에서 반복 실험할 공급자를 찾고 Qwen4B 양자화 모델을 설치했다. 한국어 생성, 인자 생성, 가상 tool 결과 이후 생성을 따로 실행했다. 모델 로딩 시간과 생성 속도를 분리했다. 아래 기존 기록의 조건·측정과 스크립트가 근거다.

### 4. 문제 해결

Ollama 업데이트·모델 설치와 도구 왕복 경로는 동작했다. 품질 문제는 해결됐다고 표시하지 않고 차량·출력 제한·가상 정보 고지를 후속 평가 항목으로 넘겼다. 가상 tool 결과 뒤 실제 최종 응답도 보존한다.

출처: `ollama-smoke-test-results.json`. 종류: **보존된 결과 파일 원문 발췌**. 원본 파일 SHA-256: `c900a0b5142cbecb765fd7ad1738241d6669dcd9b76e95cab063b8af2e3c435a`. 발췌 내용은 고치지 않았다.

```json

```


### 5. 검증 — 개선 결과·대가·남은 한계

로컬 공급 확보는 완료했지만 이 여행 쿼리의 ‘좋은 답변’은 당시 확보하지 못했다. 다른 질문에서 성공한 후속 메모리 답변을 이 쿼리의 개선 결과로 대체하지 않는다. 콜드 스타트·한 건의 속도를 일반 처리량으로 주장하지 않는다. 후속005의 기대 행동과009의 근거·불확실성 검증으로 연결한다.

## 질문과 가설

호출 과금 부담을 줄이고 반복 실험하기 위해 로컬 8GB GPU에서 도구 호출 모델을 실행할 수 있는지 확인한다. 로컬 실행은 호출 과금이 없지만 전력·장비·운영 비용과 처리량 제약이 있다.

## 변경과 조건

- Ollama 0.9.0 → 0.40.5 업데이트.
- 사용자 요청으로 기존 smollm2:135m, qwen2.5:0.5b, qwen3:0.6b 삭제.
- qwen3.5:4b-q4_K_M 설치. 4.2B, Q4_K_M, 다운로드 3,324,173,934 bytes.

- RTX 3080 Laptop GPU, 8GB VRAM.
- 문맥 4096, think=false, temperature=0, 최대 출력 256 토큰, 단일 순차 요청.
- 실행: 루트 ollama-smoke-test.ps1. 로컬 원본은 ollama-smoke-test-results.json이며 Git에서 제외.

## 관찰

- 한국어 응답 1건: 전체 80.393초, 모델 로딩 44.778초. 생성 구간 90.25 tokens/s. 콜드 스타트 수치이며 지속 처리량 벤치마크가 아니다.
- 도구 호출 1건: 0.920초. origin=서울, budget_total_krw=400000, travelers=2, has_car=false를 정확히 전달.
- 가상 도구 결과 이후 최종 답변 1건: 0.842초. 실제 검색을 수행하지 않았으며 가상 가격을 전달했다.
- 100% GPU 적재 확인. Ollama 보고 size_vram=3,140,495,604 bytes. OS·화면 등 다른 GPU 메모리를 포함한 총점유와 다르다.

## 실패와 해석

1. 차 없이 여행한다는 요청에 자동차 이동을 설명함: 조건 준수 실패.
2. 3문장 이내 지시를 초과함: 출력 제약 실패.
3. 도구 결과가 가상·미검증 가격임에도 최종 답변에서 고지하지 않음: 근거·불확실성 전달 실패.

스크립트의 기본 성공 판정은 응답과 도구 왕복이 작동하는지만 확인했다. 여행 추천 품질이 통과했다는 뜻은 아니다. 한 번의 사례로 모델 우열이나 일반 성공률을 주장하지 않는다.
