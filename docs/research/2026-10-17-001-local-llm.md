# 001 — 로컬 LLM 공급과 초기 실패

## 로컬 모델은 실행됐지만, 여행 답변은 아직 부족했다

### 문제 정의

8GB GPU에서 여행 질문에 답하고 도구를 호출할 수 있는지부터 확인했다. 첫 테스트에서는 차가 없다는 조건과 세 문장 제한을 함께 줬다.

> **💬 테스트 질문**
>
> 서울에서 출발해 차 없이 두 명이 총 40만 원 예산으로 1박 2일 여행을 하려고 해. 후보 지역 두 곳과 선택 이유를 세 문장 이내로 알려줘. 확정 가격은 필요 없어.

**🤖 첫 번째 응답**

```text
**1. 서울 근교 자연공원 (예: 이천 화천)**
서울에서 차로 30 분 내외로 접근 가능하여 이동 부담이 적습니다.
산책과 간단한 식사만으로도 예산을 효율적으로 사용할 수 있습니다.
자연 친화적인 분위기에서 두 명이 여유롭게 시간을 보내기 좋습니다.

**2. 서울 외곽 역사 문화 지역 (예: 안양 또는 평택)**
교통 인프라가 잘 되어 있어 접근성이 높고 다양한 체험 프로그램이 가능합니다.
역사적 유적과 현지 음식으로 구성된 저렴한 코스 구성이 용이합니다.
문화적 경험을 쌓으면서도 40 만 원 예산 내에서 만족스러운 여행이 될 것입니다.
```



### 문제 분석

답변은 나왔지만 차가 없다는 요청에 자동차 이동을 설명했고, 세 문장도 넘겼다. 한글 응답이 나온다는 것과 조건을 지킨다는 것은 다른 문제였다.

### 연구 과정

Ollama와 Qwen4B 양자화 모델을 준비한 뒤, 이번에는 모델이 여행 조회 도구의 인자를 만들고 결과를 받아 답할 수 있는지 확인했다. 실제 여행 검색 대신 춘천·28만 원이라는 가상 결과를 돌려줬다. 첫 테스트와는 다른 질문·조건의 도구 왕복 테스트다.

> **💬 테스트 질문**
>
> 서울 출발, 차 없이 두 명, 전체 총예산 40만 원으로 여행 후보를 찾아줘.

**🤖 가상 도구 결과를 받은 뒤의 응답**

```text
서울 출발, 차 없이 2 명으로 여행하시려는 경우 전체 예산 40 만 원 내에서 **춘천**을 방문하는 여행이 가능합니다.

*   **목적지**: 춘천
*   **교통 수단**: 대중교통
*   **예상 총 비용**: 280,000 원
```



### 문제 해결

서울·40만 원·2명·차량 없음이라는 도구 인자는 맞게 전달됐다. 다만 최종 답변에는 가상 데이터이고 가격을 확인하지 않았다는 설명이 빠졌다. 그래서 연결 테스트 통과와 여행 추천 품질 통과를 분리했다.

### 결과와 남은 문제

로컬 모델을 공급자로 쓰는 기반은 확보했다. 하지만 이 여행 질문의 품질 문제를 해결했다고 보지는 않았다. 이후 평가에는 조건 준수, 답변 길이, 가상·미확인 정보 고지를 따로 넣기로 했다.

## 구현과 실험 상세

날짜: 2026-10-17 (Asia/Seoul). 상태: 기본 동작 확인, 품질 과제 발견.

## 질문과 가설

호출 과금 부담을 줄이고 반복 실험하기 위해 로컬 8GB GPU에서 도구 호출 모델을 실행할 수 있는지 확인한다. 로컬 실행은 호출 과금이 없지만 전력·장비·운영 비용과 처리량 제약이 있다.

## 변경과 조건

- Ollama 0.9.0 → 0.40.5 업데이트.
- 사용자 요청으로 기존 smollm2:135m, qwen2.5:0.5b, qwen3:0.6b 삭제.
- qwen3.5:4b-q4_K_M 설치. 4.2B, Q4_K_M, 다운로드 3,324,173,934 bytes.
- digest: d8b0f5e9760cd1682034f292d7ef72ec46f432149be0df7574bf2d6e92e38c04.
- RTX 3080 Laptop GPU, 8GB VRAM.
- 문맥 4096, think=false, temperature=0, 최대 출력 256 토큰, 단일 순차 요청.
- 실행: 루트 ollama-smoke-test.ps1. 로컬 원본은 ollama-smoke-test-results.json이며 Git에서 제외.

## 관찰

- 한국어 응답 1건: 전체 80.393초, 모델 로딩 44.778초. 생성 구간 90.25 tokens/s. 콜드 스타트 수치이며 지속 처리량 벤치마크가 아니다.
- 도구 호출 1건: 0.920초. origin=서울, budget_total_krw=400000, travelers=2, has_car=false를 정확히 전달.
- 가상 도구 결과 이후 최종 답변 1건: 0.842초. 실제 검색을 수행하지 않았으며 가상 가격을 전달했다.
- 100% GPU 적재 확인. Ollama 보고 size_vram=3,140,495,604 bytes. OS·화면 등 다른 GPU 메모리를 포함한 총점유와 다르다.

## 실패와 해석

1. 차 없이 여행한다는 요청에 자동차 이동을 설명함: 조건 준수 실패.
2. 3문장 이내 지시를 초과함: 출력 제약 실패.
3. 도구 결과가 가상·미검증 가격임에도 최종 답변에서 고지하지 않음: 근거·불확실성 전달 실패.

스크립트의 기본 성공 판정은 응답과 도구 왕복이 작동하는지만 확인했다. 여행 추천 품질이 통과했다는 뜻은 아니다. 한 번의 사례로 모델 우열이나 일반 성공률을 주장하지 않는다.
