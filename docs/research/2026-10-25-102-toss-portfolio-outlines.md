# 102 · 두 공고에 맞춘 포트폴리오 전개와 제목

사용자 요청에 따라 본문 없이 공고별 전개 순서와 파트 제목만 정했다. 제목은 검토할 목차안이며 확정 원고로 취급하지 않는다.

공고1은 제품과 사용 흐름을 먼저 보여준 뒤 문맥·웹 근거·행동 제어·평가로 전개한다. 공고2는 제품 소개 뒤 실행 구조·추적·메모리·평가·운영 설계로 이어진다. 공고별 지식노트와 사람이 읽는 포트폴리오 편집 규칙을 기준으로 선택했다.

기존 공고 분석 Notion 페이지 아래에 공고별 목차 페이지를 만들었다. 각 페이지에는 제목만 두고 본문·이미지·수치·코드·PDF는 추가하지 않는다. 목차의 전개 의도와 작업 기록은 이 연구일지에 분리했다.

목차: [공고별 전개와 제목](../portfolio/toss-outlines.md).

Notion: [공고1 목차](https://app.notion.com/p/404d058c022e813091e8dc0606bbbdf5), [공고2 목차](https://app.notion.com/p/404d058c022e8176a4dacfe26bc290d9). 저장 후 두 페이지 모두 파트 제목만 있는지 재조회했다.

제품·모델·실험 변경은 없으며 실험용 도구 호출 로그도 없다. 문서 저장과 Notion 재조회로 요청 범위를 확인한다.
