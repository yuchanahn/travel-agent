# 106 · 개발 계기·모델 선택 설명과 캡처 순서

사용자가 현재 포트폴리오에 여행 에이전트의 개발 계기와 Qwen 선택 이유가 있는지 확인하고 즉시 촬영할 목록을 요청했다. 실제 Notion 두 페이지에서 일반적인 제품 목적만 있고 개인 경험에서 출발한 계기와 모델 선택 이유는 빠져 있음을 확인했다.

두 페이지의 도입에 여행 준비 중 Codex를 사용하며 느낀 토큰 소비와 결과의 불편을 반영했다. Ollama/Qwen 설명은001의8GB GPU 환경·양자화 모델 실행·구조화 도구 왕복,071의외부 공급자 의존을 줄인 복귀 결정을 근거로 짧게 추가했다. 다른 모델보다 우수해서 골랐다는 비교를 만들지 않았다.

캡처 우선순위는 같은 실행의 호출 트리 → 검색 도구 상세 → 다음 모델 입력 → 메모리/Context 처리로 정했다. 개발 연구 분담과 검색 원문/발췌 대조는 추가 장면으로 분리했다. 제품 첫 화면과 계획서는 기존 자료를 사용한다.

실제 모델·검색·촬영을 새로 실행한 작업이 아니며 새 실험용 도구 로그는 없다. 변경은 두 원고·Notion의 도입과 [캡처 가이드](../portfolio/trace-capture-brief.md)다.
