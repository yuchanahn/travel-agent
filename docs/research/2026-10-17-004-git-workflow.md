# 004 — 변경 완료 시 커밋·푸시 정책

## 문제에서 검증까지 — 변경과 검증 결과를 커밋 이력에 연결하기

보강일: 2026-10-17. 아래는 기존 기록·보존 산출물에 근거한 보강이며, 당시 기록은 뒤에 남겼다. 재실행 출력에는 시점과 코드 버전을 별도로 표시한다.

**흐름:** 작업 결과가 흩어짐 → 검증·기록 후 커밋·푸시 규칙 → 변경 이력 추적

### 1. 문제 정의 — 요청과 초기 결과

사용자는 변경 완료마다 커밋·푸시하도록 요청했다. 이 단계의 결과물은 더 좋은 자연어 답변이 아니라 검증과 구현 변경을 따라갈 수 있는 이력이다. 초기에는 완료와 원격 반영을 매번 연결하는 협업 규칙이 없었다.

### 2. 문제 분석

파일 변경, 로컬 커밋, 원격 푸시는 다른 상태다. 개인 로그나 관련 없는 변경까지 일괄 스테이징하면 재현성과 공개 범위가 흐려진다.

### 3. 연구 과정

작업 파일만 지정해 스테이징하고 검증·노션 기록 후 커밋·푸시하는 순서를 정했다. 강제 푸시나 이력 재작성은 포함하지 않는다.

### 4. 문제 해결

AGENTS에 지속 승인과 작업 범위·실패 보고 규칙을 넣었다. 아래는 이번 문서 보강 이전 로컬 이력을 읽은 실제 stdout이다.

### 5. 검증 — 개선 결과·대가·남은 한계

명령: `git log -4 --format="%h %s"`. 재실행 시작(UTC): `2026-10-17T11:05:31.599824+00:00`. 코드: `e6fd0f5`. 종료 코드: `0`. 아래는 **이번 보강 시점의 재실행 stdout**이며 최초 구현 당시 출력이 아니다.

출처: `artifacts/research-evidence-2026-10-17/git-history.stdout.txt`. 종류: **현재 재실행 stdout 전체**. 원본 파일 SHA-256: `7af00faa10a56b487f22e87286832be0c606fb68e5857486d8f6197a88ca8604`. 발췌 내용은 고치지 않았다.

```text
e6fd0f5 feat: add agentic memory RAG with bounded tool loop and execution traces
1d998b6 docs: explain all memory RAG code with source excerpts and diagrams
2a2b49c feat: add scoped conversation memory RAG with hybrid retrieval
76c6b88 docs: research hybrid travel RAG and reranking design
```

이 stdout은 로컬 커밋 존재만 증명한다. 원격 푸시 성공을 이 출력만으로 주장하지 않는다. 과거 푸시 stdout 전체는 보존 파일이 없으며 이번 보강의 실제 커밋·푸시는 완료 결과로 따로 기록한다.

## 기존 상세 기록 — 작성 당시의 구현·실험·해설

날짜: 2026-10-17 (Asia/Seoul).

사용자가 앞으로 변경 작업 완료 시 커밋·푸시를 수행하도록 승인했다. AGENTS.md에 의미 있는 변경 단위의 검증·연구 기록·커밋·푸시 절차를 추가했다. origin은 https://github.com/yuchanahn/travel-agent.git, 현재 브랜치는 main으로 확인했다.

이번 작업의 파일만 명시적으로 스테이징하며 비밀정보·개인 원본 로그·관련 없는 사용자 변경을 제외한다. 강제 푸시와 이력 재작성은 하지 않는다. 푸시 실패 시 로컬 커밋을 보존하고 보고한다. 완료 응답에 실제 커밋과 푸시 상태를 남긴다.
