# 공고별 포트폴리오 목차안

## 공고1 · 토스 AI Engineer

1. 여행 준비에서 시작한 AI 에이전트
2. 대화를 조사와 계획서로 연결하기
3. 조건을 기억하는 메모리와 RAG
4. 웹 근거를 고르는 검색·데이터 흐름
5. 행동을 제어하는 Tool Calling과 가드레일
6. 응답을 평가하고 개선하는 실험 설계

## 공고2 · 토스증권 AI Engineer

1. 여행 요청을 처리하는 AI 에이전트
2. 도구와 실행을 연결하는 오케스트레이션
3. 행동 경로를 추적하는 Observability
4. 대화와 근거를 관리하는 Memory
5. 품질 기준을 검증하는 평가 하네스
6. 안정성과 사용자 통제를 고려한 운영 설계
