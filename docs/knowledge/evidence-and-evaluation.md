## 다음 작업에서 사용할 판단

| 관찰 | 말할 수 있는 범위 | 아직 입증되지 않은 것 |
| --- | --- | --- |
| HTTP200·본문 수집 성공 | 접근·추출 경로가 동작했다 | 관련 근거 확보·추천 정확성 |
| completed·인용 ID 존재 | 실행 종료·출처 식별자 연결 | 주소·시설·가격·인용 의미의 정확성 |
| 저장 입력 재생·패킷 축소 | 같은 자료에서 전달 형식·크기 변화 | 새 검색 결과·최종 품질 향상 |
| 합성 메모리의 세부 복원 | 고정 사례에서 원문 근거 사용 가능 | 모든 대화의 장기 기억·압축 손실 복원 |
| 모델 `length`·output_limit | 공급자 출력 예산 소진 | 모델 자율 종료·반복 탐지로 중단 |
| 테스트·UI 동작 통과 | 해당 계약·사용 흐름 동작 | 실제 여행 추천의 근거 통과 |

실제 추천은 고정 질문을 유지하고 실행 성공과 사람의 근거 검토를 따로 기록한다. 모델/도구/HTTP 횟수·오류·입출력 토큰을 구분하며 누락된 값을0으로 만들지 않는다. 이전 Claude 결과는 같은 로컬 Qwen을 다른 하네스에서 실행한 결과임을 밝힌다.

## 근거와 한계

079와095에서 실행 종료와 실제 근거 검토가 갈렸다. 후보의 각 주장은 그 후보의 출처·날짜·인원·가격 조건에 연결해야 한다. 시설을 다른 숙소에서 가져오거나 제3자 정보를 공식 확인으로 묶지 않는다. 현재 가격·영업 정보는 과거 원문에 있다는 이유만으로 최신이라고 하지 않는다.

082의 합성 평가와095의 저장응답 재생은 각각의 입력 조건에 한정된다. 097에서 관찰한 출력 잘림의 원인을 모든 반복의 원인으로 일반화하지 않는다. 현재 실패를 지식으로 남겼다는 사실이 실패를 해결했다는 뜻은 아니다.
