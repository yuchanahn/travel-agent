# 개발 단계

## 현재 완료

- 로컬 모델 설치와 기본 도구 왕복 테스트
- 프로젝트 배경, 초기 기술 방향, 연구 기록 방식
- Python 패키지 메타데이터와 읽기 전용 상태 조회 CLI

## 다음: 제품과 데이터

- 실제 여행 요청 예시 5개와 추천 완료 조건 정의
- 여행지·교통 접근성 데이터의 출처·라이선스·갱신 주기 확인
- 첫 읽기 전용 도구 구현과 결과 스키마 결정

## 다음: 에이전트 핵심

- 모델 어댑터와 허용 도구 레지스트리
- 구조화된 도구 호출 반복, 세션 대화 유지, 추가 질문과 종료
- 인자 검증, 오류 결과, 횟수·시간 제한
- trajectory와 토큰·시간 기록, 개인 정보 처리

## 다음: 평가

- 제약 준수, 근거, 불확실성, 추가 질문, 실패 대응 사례
- 같은 모델·동일 입력의 직접 답변 vs 도구 기반 에이전트
- 필요 시 범용 Codex와 제품 효용 비교, 모델·도구 차이를 명시
- 수동 평가부터 시작하고 실제 사용 실패를 회귀 사례로 추가

## 다음: 사용자와 공개

- 웹 API·사용자 화면, 세션 격리·요청 큐·사용량 제한
- 앱 Docker 구성과 실행 재현성 확인
- 공개 라이선스·문서·데이터 이용 조건, 비밀정보 검사
- GitHub 저장소 연결과 공개
- 소수 사용자 실사용, 재사용 여부와 실패 수정
